# MC Mobicare Scratch & Win

Next.js, PostgreSQL, Prisma and Zod production campaign implementation. The supplied logo is preserved at `public/brand-logo.png`; its royal blue and gold provide the light premium visual theme.

Copy `.env.example` to `.env`, then run `npm install`, `npm run db:migrate`, `npm run db:seed`, and `npm run dev`. Visit `/scratch` (or branch QR URLs when enabled). Before deployment, set a strong `AUTH_SECRET`, production database URL, and HTTPS public URL.
